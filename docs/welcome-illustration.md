# Illustrated welcome screen

Design 3 keeps the existing sidebar, microphone, and composer. The decorative
landscape and blue/rose glow fade out over 600ms when voice mode starts or the
first message arrives. The microphone keeps its existing calm glide. Ending or
exiting voice does not bring the artwork back over an existing conversation.
Reduced motion removes the illustration transition.

Asset: `public/illustrations/welcome-landscape.png` (2172 x 724, transparent PNG).
Generated with the built-in image generation tool using the approved Design 3
mockup as a reference. The original generated file is retained in Codex's image
output folder; the application uses this repository's copy.

## Generation prompt

Use case: background-extraction / illustration-story.
The reference is an approved UI mockup. Create ONLY its delicate decorative landscape illustration as a reusable web asset on a genuinely transparent background with alpha, not a new screenshot.
Preserve the thin, graceful pale slate-blue and blush-rose line-art style. Composition: a little home and rounded tree near the far left; a warm minimal outline family of two adults and a child holding hands near the far right, a thin rose heart above them; a few small softly colored trees; long low flowing blue and rose landscape curves connecting the left and right scenes across the bottom third. Leave the middle 40 percent mostly empty so a live microphone and text can sit above it.
Wide panoramic landscape, about 3:1. Whole art visible with breathing room at edges, no cropped people or house. Pale airy colors but lines visible against ice blue #e5effb, extremely sparse pastel filled tree shapes. No raster white rectangle and no baked background gradient; all empty space must be transparent.
REMOVE ALL UI: no Lincoln logo, no microphone, no circles or halo around a microphone, no sidebar, no cards, no buttons, no input box, no lettering, no words, no watermark. The output is exclusively the home/family/landscape illustration.
