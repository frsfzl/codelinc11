# codelinc11 — LincLife

LincLife landing page and AI coverage guide, built with Vite + React 19 + Tailwind CSS v4.

## Getting started

```sh
npm install
npm run dev      # start the dev server
npm run build    # type-check and build to dist/
npm run preview  # serve the production build
```

## Structure

- `src/App.tsx` — Home and Assistant screens, chat flow, recommendation logic
- `src/index.css` — Tailwind import, `@theme` design tokens, base styles and animations
- `docs/design-handoff/` — original design handoff (spec README, HTML prototype, reference source)
